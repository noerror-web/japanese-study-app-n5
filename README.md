A state-of-the-art, feature-packed Android application designed for **JLPT N5 Japanese language learners**. Built with modern Android stack (Kotlin + Jetpack Compose) and powered by **Google Gemini AI** for intelligent translations, grammar breakdowns, and real-time interactive practice.

---

## 🌟 Key Features

### 🤖 AI-Powered Learning Assistant
- **Gemini 3.6 Flash Integration**: Instant sentence translations, Romaji conversions, and detailed grammar breakdowns.
- **Interactive Quiz Generator**: Dynamically generates JLPT N5 multiple-choice practice questions with full explanations.
- **Kanji & Vocabulary Breakdown**: Deep dive into individual kanji meanings, stroke counts, and usage examples.
- **Conversation Practice**: Real-world situational dialogues (e.g., ordering at a cafe, asking for directions).

### 📚 Complete JLPT N5 Curriculum
- Comprehensive N5 vocabulary list with search and filtering.
- Essential grammar rules with clear explanations and usage tips.
- Audio pronunciations and Text-To-Speech (TTS) integration.
- Daily streak tracking and study reminder notifications.

### 🛡️ Online License & Cloud Syncing System
- **Real-Time License Management**: Dynamic online validation powered by Cloud Firestore.
- **Secure Key Provisioning**: Centralized online AI key management — no sensitive API keys embedded in client source code.
- **Owner Dashboard**: Dedicated dashboard for license generation, key cleanup, and user access management.

### 🎨 Premium UI & Design System
- Modern **Sakura Light** & **Tokyo Night** theme modes.
- Dynamic glassmorphic UI elements, smooth micro-animations, and responsive layouts.

## 🛠️ Tech Stack

- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) with Material 3
- **Language**: 100% [Kotlin](https://kotlinlang.org/)
- **AI Backend**: [Google Generative Language API (Gemini 3.6 Flash)](https://ai.google.dev/)
- **Database & Sync**: [Firebase Cloud Firestore](https://firebase.google.com/docs/firestore) & [Firebase Auth](https://firebase.google.com/docs/auth)
- **Background Jobs**: Android WorkManager & AlarmManager
- **Build System**: Gradle Kotlin DSL
