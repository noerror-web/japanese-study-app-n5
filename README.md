A state-of-the-art, feature-packed Android application designed for **JLPT N5–N1 Japanese language learners**. Built with modern Android stack (100% Kotlin + Jetpack Compose) and pre-bundled with an **Offline Full N1–N5 Dictionary** and **Tatoeba Example Sentences Dataset**.

---

## 🚀 What's New in Version 2.0

- 📚 **Full JLPT N1–N5 Dictionary Dataset**: Pre-bundled with **22,636 official JMdict vocabulary entries** and **10,384 official KANJIDIC2 entries**.
- 💬 **12,196 Tatoeba Example Sentences**: Rich Japanese-English & Japanese-Bengali example sentence pairs complete with **Furigana bracket annotations**.
- 🈁 **Dedicated Kanji Detail Bottom Sheet**: Tapping any Kanji opens a bottom sheet showing stroke counts, On'yomi (音読み), Kun'yomi (訓読み), English/Bengali meanings, compound words, and Tatoeba example sentences.
- 📶 **Smart N5 → N1 Search Ordering**: Global search and dictionary search results strictly prioritize **JLPT N5 entries first**, followed by N4, N3, N2, and N1.
- ⚙️ **Furigana & "Disable Kanji (Kana Only)" Settings**: Option to view Furigana above Kanji or convert all Japanese text into pure Hiragana & Katakana across example sentences and app screens.

---

## 🌟 Core Features

### 📖 Offline Expanded Dictionary & KANJIDIC2
- **22,636 Words**: Complete JMdict coverage with exact JLPT N1–N5 classification, readings, and meanings.
- **10,384 Kanji**: Complete KANJIDIC2 dataset with On'yomi, Kun'yomi, Nanori, stroke counts, and grade levels.
- **12,196 Example Sentences**: Sourced from Tatoeba with real-time Furigana text rendering.

### 🔍 Universal Search System
- Global search from home screen across **23,000+ words, kanji, and grammar lessons**.
- Fast asynchronous filtering with instant interactive detail sheets.

### 🤖 AI-Powered Learning Assistant
- **Gemini 3.6 Flash Integration**: Instant sentence translations, Romaji conversions, and detailed grammar breakdowns.
- **Interactive Quiz Generator**: Dynamically generates JLPT multiple-choice practice questions with full explanations.
- **Conversation Practice**: Real-world situational dialogues (ordering at a cafe, asking directions, hotel check-in).

### 🎨 Premium UI & Customization
- Modern **Sakura Light** & **Tokyo Night** theme modes.
- Dynamic glassmorphic UI elements, smooth micro-animations, and responsive layouts.
- **Bengali (বাংলা) & English Language Support**.

## 🛠️ Tech Stack

- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) with Material 3
